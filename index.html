    Bot Telegram

    Cara termudah menerima alert: buka @Testisuubot di Telegram dan kirim /daftar. Bot berjalan di server, jadi tidak perlu mengisi token di halaman ini. Formulir di bawah hanya untuk memakai bot Anda sendiri langsung dari browser.

    Telegram belum diatur.

    Cara menyambungkan

    1. Di Telegram, chat ke @BotFather, kirim /newbot, salin token yang diberikan.
    2. Buka bot baru Anda, tekan Start dan kirim pesan apa saja.
    3. Tempel token di sini, klik Cari chat ID, lalu Simpan.
    4. Klik Kirim pesan tes. Jika pesan masuk, centang kirim alert.

    Token disimpan di browser ini saja (localStorage) dan hanya dikirim ke api.telegram.org. Alert dan perintah hanya berjalan selama halaman ini terbuka; untuk jalan terus tanpa browser pakai flow Node-RED. Jangan aktifkan keduanya dengan bot yang sama, karena alert akan ganda dan penerimaan perintah saling bentrok.
